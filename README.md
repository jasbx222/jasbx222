### Cabinet 01 — Debug the Alien
```csharp
public User GetUser(int id)
{
    var cached = _cache.Get(id);
    if (cached is null)
        return _db.Users.Find(id); // result never stored
    return cached;
}
```
The lounge keeps burning fuel. Every guest asks for the same record, and the database answers every time.
<details>
<summary>Open the core</summary>
The miss is never written back, so the next request misses again. Read-through caching stores the row after the first database hit, and invalidation clears it when the user changes.
</details>
