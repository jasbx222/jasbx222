## 👾 The Arcade · جناح الألعاب

ثلاث ماكينات. الأولى لغز، الثانية قصة بأبواب، الثالثة لوحة نقاط.

### Cabinet 01 — Debug the Alien

الكونسول يصرخ. الضيف يطلب نفس السجل، والداتابيس ترد كل مرة. المحطة تحرق وقود.

```csharp
public User GetUser(int id)
{
    var cached = _cache.Get(id);
    if (cached is null)
        return _db.Users.Find(id); // never written back

    return cached;
}
```

<details>
<summary>🔓 افتح النواة · Open the core</summary>

الفشلة ما تنكتب بالكاش، فالطلب الجاي يفشل مرة ثانية.  
التخزين الصح: بعد أول قراءة من الداتابيس احفظ الصف في Redis، ولما المستخدم يتغير امسح المفتاح. هذا cache invalidation، مو ضربة قاعدة لكل ضيف.

</details>
