## الألعاب

ثلاث ألعاب قصيرة. افتح الوحدة والعب من جوا.

<details>
<summary><b>1 · حجر ورقة مقص</b> — ضد المحطة</summary>

<br/>

المحطة تختار ورا الستار. أنت اختار:

<details>
<summary>حجر</summary>
المحطة لعبت ورقة. الورقة تغطي الحجر. خسرت هالجولة.
</details>

<details>
<summary>ورقة</summary>
المحطة لعبت حجر. ورقتك غطته. فزت.
</details>

<details>
<summary>مقص</summary>
المحطة لعبت مقص. تعادل.
</details>

</details>

<details>
<summary><b>2 · مهمة الباب</b> — اجمع قطعتين وافتح الهندسة</summary>

<br/>

الباب يبي تصريح JWT ومفتاح Redis. لا تشرب من أنبوب التبريد.

<details>
<summary>روح البار</summary>

النادل يعطيك تصريح JWT.

<details>
<summary>روح الأركيد</summary>

لقيت مفتاح Redis تحت الماكينة.

<details>
<summary>افتح باب الهندسة</summary>

<b>الباب انفتح.</b> تصريح ومفتاح، ودخلت. هذي الفكرة: حل القفل، بعدين اكتب الكود.
</details>

</details>

</details>

<details>
<summary>اشرب من أنبوب التبريد</summary>
خسرت. مو كل شي بالبار ينشرب. ارجع وابدأ من البار.
</details>

</details>

<details>
<summary><b>3 · وين الخلل؟</b></summary>

<br/>

```csharp
if (cached is null)
    return _db.Users.Find(id); // ما ينحفظ
```

كل طلب يضرب الداتابيس. ليش؟

<details>
<summary>الجواب</summary>

النتيجة ما تنكتب بالكاش، فالطلب الجاي يفشل مرة ثانية. احفظ الصف بعد أول قراءة، وامسح المفتاح لما البيانات تتغير.
</details>

</details>
